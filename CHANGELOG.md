# Changelog

All notable changes to this project are documented in this file.
<br>*Alle nennenswerten Änderungen an diesem Projekt werden in dieser Datei dokumentiert.*

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) (pre-release `-beta` versions).
<br>*Das Format basiert auf [Keep a Changelog](https://keepachangelog.com/de/1.1.0/), und dieses Projekt hält sich an [Semantic Versioning](https://semver.org/lang/de/) (Vorabversionen mit `-beta`).*


## [0.9.18-beta] - 2026-10-17

### Added

- Changelog following Keep a Changelog, written in English with German translations.
  <br>*Changelog nach Keep a Changelog, auf Englisch mit deutschen Übersetzungen.*

### Changed

- Project rules: code in English only; changelog entries in English with a German translation.
  <br>*Projektregeln: Code ausschließlich auf Englisch; Changelog-Einträge auf Englisch mit deutscher Übersetzung.*


## [0.9.17-beta] - 2026-10-18

### Added

- Show the current energy flow on the now tab.
  <br>*Aktuellen Energiefluss auf dem Jetzt-Tab anzeigen.*

### Changed

- Issue forms are bilingual (English / German).
  <br>*Issue-Formulare sind zweisprachig (Englisch / Deutsch).*


## [0.9.15-beta] - 2026-10-18

### Added

- Status badges in the README.
  <br>*Status-Badges in der README.*

### Changed

- Wiki and README are bilingual (English and German).
  <br>*Wiki und README sind zweisprachig (Englisch und Deutsch).*


## [0.9.12-beta] - 2026-10-18

### Fixed

- Year range charts: daily peaks for effective power and daily mean power from energy.
  <br>*Jahresbereich-Diagramme: Tagesspitzen für die effektive Leistung und mittlere Tagesleistung aus der Energie.*


## [0.9.11-beta] - 2026-10-18

### Changed

- Clarify the percentages in the power chart tooltip.
  <br>*Prozentangaben im Tooltip des Leistungsdiagramms verständlicher gemacht.*


## [0.9.10-beta] - 2026-10-18

### Added

- Issue tracker with bug report and feature request forms.
  <br>*Issue-Tracker mit Formularen für Fehlermeldungen und Funktionswünsche.*


## [0.9.9-beta] - 2026-10-18

### Added

- Power chart per string on the power tab.
  <br>*Leistungsdiagramm pro String auf dem Leistungs-Tab.*


## [0.9.8-beta] - 2026-10-18

### Changed

- Rename the yearly storage level lines to daily high, average and low.
  <br>*Jährliche Speicherstand-Linien in Tageshoch, Durchschnitt und Tagestief umbenannt.*


## [0.9.7-beta] - 2026-10-18

### Added

- Minimum storage level setting; the usable capacity is derived from it.
  <br>*Einstellung für den minimalen Speicherstand; die nutzbare Kapazität wird daraus abgeleitet.*


## [0.9.6-beta] - 2026-10-18

### Changed

- Storage tab uses daily highs and lows; energy counters are used for best and weakest days.
  <br>*Speicher-Tab nutzt Tageshöchst- und -tiefstwerte; Energiezähler bestimmen bester und schwächster Tag.*


## [0.9.5-beta] - 2026-10-18

### Added

- Wiki pages and a workflow that publishes them to the GitHub wiki.
  <br>*Wiki-Seiten und ein Workflow, der sie ins GitHub-Wiki veröffentlicht.*


## [0.9.4-beta] - 2026-10-18

### Changed

- Price sensor values are shown as read-only fields in the plant settings; number field arrows removed.
  <br>*Preissensor-Werte werden in den Anlageneinstellungen als schreibgeschützte Felder angezeigt; Pfeile an Zahlenfeldern entfernt.*


## [0.9.3-beta] - 2026-10-18

### Added

- Year ranges for the storage and forecast tabs.
  <br>*Jahresbereiche für den Speicher- und den Prognose-Tab.*

### Fixed

- Direct consumption and autarky with gaps in the house sensor.
  <br>*Direktverbrauch und Autarkie bei Lücken im Hausverbrauchssensor.*


## [0.9.2-beta] - 2026-10-18

### Added

- String orientation, plant location, improvement suggestions, year ranges in history and key figure cards.
  <br>*String-Ausrichtung, Anlagenstandort, Verbesserungsvorschläge, Jahresbereiche im Verlauf und Kennzahlen-Karten.*


## [0.9.1-beta] - 2026-10-18

### Added

- Calendar-year range on the analysis tab.
  <br>*Kalenderjahr-Bereich im Analyse-Tab.*

### Changed

- Rename the rolling year to 12 months.
  <br>*Das gleitende Jahr heißt jetzt 12 Monate.*


## [0.9.0-beta] - 2026-10-18

### Added

- Storage and forecast tabs.
  <br>*Speicher- und Prognose-Tab.*

### Fixed

- Energy totals with young filtered sensors.
  <br>*Energiesummen bei jungen gefilterten Sensoren.*


## [0.8.3-beta] - 2026-10-17

### Changed

- Analysis tab: energy counter totals, clearer hints, forecast from history, weakest day.
  <br>*Analyse-Tab: Summen aus Energiezählern, klarere Hinweise, Prognose aus dem Verlauf, schwächster Tag.*


## [0.8.2-beta] - 2026-10-17

### Added

- Year range on the analysis tab and field descriptions for the grid step.
  <br>*Jahresbereich im Analyse-Tab und Feldbeschreibungen für den Netz-Schritt.*


## [0.8.1-beta] - 2026-10-17

### Changed

- Restyle the panel after the Glow dashboard design.
  <br>*Panel nach dem Glow-Dashboard-Design neu gestaltet.*


## [0.8.0-beta] - 2026-10-17

### Added

- Grid/consumption inputs, analysis tab, string fault sensor, forecast log and yearly benefit.
  <br>*Netz-/Verbrauchseingaben, Analyse-Tab, String-Störungssensor, Prognose-Protokoll und Jahresnutzen.*


## [0.7.4-beta] - 2026-10-17

### Fixed

- Per-sensor deviation for new sensors and older years.
  <br>*Abweichung pro Sensor bei neuen Sensoren und älteren Jahren.*


## [0.7.2-beta] - 2026-10-17

### Added

- Effective string power in percent.
  <br>*Effektive String-Leistung in Prozent.*

### Fixed

- Table view.
  <br>*Tabellenansicht.*


## [0.7.0-beta] - 2026-10-17

### Added

- Settings tab for custom string names and peak power, stored in Home Assistant.
  <br>*Einstellungs-Tab für eigene String-Namen und Spitzenleistung, gespeichert in Home Assistant.*
- Option to use the magnitude of storage in/out power sensors that report negative values.
  <br>*Option, bei Speicher-Leistungssensoren mit negativen Werten den Betrag zu verwenden.*

### Changed

- Storage line is colored by direction: into storage pink, from storage teal.
  <br>*Speicherlinie nach Richtung eingefärbt: in den Speicher rosa, aus dem Speicher türkis.*


## [0.6.7-beta] - 2026-10-16

### Fixed

- Direct consumption exceeding production with signed storage sensors.
  <br>*Direktverbrauch über der Erzeugung bei Speichersensoren mit Vorzeichen.*


## [0.6.6-beta] - 2026-10-16

### Changed

- Split values by source in the chart tooltips.
  <br>*Werte in den Diagramm-Tooltips nach Quelle aufgeteilt.*


## [0.6.5-beta] - 2026-10-16

### Added

- Power tab with per-string power against the measured maximum.
  <br>*Leistungs-Tab mit String-Leistung im Verhältnis zum gemessenen Maximum.*


## [0.6.4-beta] - 2026-10-16

### Changed

- Beta releases carry a `-beta` version suffix.
  <br>*Beta-Releases tragen das Versionssuffix `-beta`.*


## [0.6.3] - 2026-10-16

### Changed

- Stay in beta: releases are marked as pre-release and limitations are documented.
  <br>*Beta-Status beibehalten: Releases werden als Pre-release markiert und Einschränkungen dokumentiert.*


## [0.6.2] - 2026-10-16

### Changed

- Show above-average deviation in green.
  <br>*Überdurchschnittliche Abweichung in Grün anzeigen.*

### Fixed

- Year forecast label.
  <br>*Beschriftung der Jahresprognose.*


## [0.6.1] - 2026-10-16

### Fixed

- Direct consumption for feed-in sensors with negative values.
  <br>*Direktverbrauch bei Einspeisesensoren mit negativen Werten.*


## [0.6.0] - 2026-10-16

### Added

- Forecast sensors as config flow step 3.
  <br>*Prognosesensoren als Config-Flow-Schritt 3.*


## [0.5.3] - 2026-10-16

### Changed

- Use Energy dashboard colors in the panel.
  <br>*Farben des Energy-Dashboards im Panel verwenden.*


## [0.5.2] - 2026-10-16

### Added

- Calculate PV energy used directly.
  <br>*Berechnung der direkt verbrauchten PV-Energie.*


## [0.5.1] - 2026-10-16

### Changed

- Split the panel into tabs.
  <br>*Panel in Tabs aufgeteilt.*


## [0.5.0] - 2026-10-16

### Added

- History charts and yearly overview in the panel.
  <br>*Verlaufsdiagramme und Jahresübersicht im Panel.*


## [0.3.1] - 2026-10-16

### Changed

- Release notes are generated in English from PR titles.
  <br>*Release-Notes werden auf Englisch aus PR-Titeln erzeugt.*


## [0.3.0] - 2026-10-16

### Added

- Initial PV Assistant integration with custom panel.
  <br>*Erste Version der PV-Assistant-Integration mit eigenem Panel.*
- Config flow with energy sensors, storages (as subentries) and combined sensors with switchable sign, step 2 for power sensors, and a panel with a sensor view.
  <br>*Config Flow mit Energiesensoren, Speichern (als Subentries) und Kombisensoren mit umschaltbarem Vorzeichen, Schritt 2 für Leistungssensoren und ein Panel mit Sensoransicht.*
- Release workflows and `.gitignore`.
  <br>*Release-Workflows und `.gitignore`.*
