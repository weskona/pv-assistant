# Conventions / Konventionen

- Changelog entries and code (identifiers, comments, docstrings, commit messages) are written in English, each followed by a German translation.
  <br>*Changelog-Einträge und Code (Bezeichner, Kommentare, Docstrings, Commit-Messages) werden auf Englisch geschrieben, jeweils mit deutscher Übersetzung.*
- Changelog: German translation in italics on the line below each entry (`<br>*...*`).
  <br>*Changelog: Deutsche Übersetzung kursiv in der Zeile unter jedem Eintrag.*
- Code: English comment first, German translation on the next comment line. Identifiers stay English only.
  <br>*Code: Englischer Kommentar zuerst, deutsche Übersetzung in der nächsten Kommentarzeile. Bezeichner bleiben nur Englisch.*
