# Conventions / Konventionen

- Code (identifiers, comments, docstrings, commit messages) is written in English only.
  <br>*Code (Bezeichner, Kommentare, Docstrings, Commit-Messages) wird ausschließlich auf Englisch geschrieben.*
- Changelog and README are written in English with a German translation.
  <br>*Changelog und README werden auf Englisch mit deutscher Übersetzung geschrieben.*
- Changelog: German translation in italics on the line below each entry (`<br>*...*`).
  <br>*Changelog: Deutsche Übersetzung kursiv in der Zeile unter jedem Eintrag.*
